UNDANGAN DIGITAL MALIK & KIKI — V2

CARA MEMPERBARUI
1. Ekstrak ZIP ini.
2. Buka folder hasil ekstrak.
3. Upload/replace index.html dan folder assets ke repository GitHub undangan-malik-kiki.
4. Tunggu Vercel melakukan deployment otomatis.

CATATAN PENTING SEBELUM DIBAGIKAN
- V2 ini adalah template front-end. RSVP dan buku tamu diarahkan ke WhatsApp, belum tersimpan ke database.
- Isi nomor WhatsApp tujuan pada variabel waNumber di bagian bawah index.html (gunakan kode negara, misalnya 62... tanpa tanda +).
- Ganti placeholder rekening Mandiri dan BCA di bagian modal amplop digital.
- Musik belum disertakan. Siapkan file audio yang Anda miliki hak/lisensinya, lalu simpan sebagai assets/aku-dan-kamu.mp3.
- Foto di folder assets adalah foto yang tersedia saat file dibuat (jika ada). Jika tidak ada, ganti dengan foto pasangan pilihan Anda menggunakan nama foto-cover.jpeg dan foto-pasangan-1.jpeg.
- Nama tamu personal: tambahkan parameter URL, contoh ?to=Bapak%20Budi.
- Periksa seluruh data dan tampilan di ponsel sebelum membagikan tautan.
